How it is built

  • Each dashboard is compiled from one JSON source of truth, refreshed after every 10-Q, 8-K and earnings call, with source links and as-of dates on each record.
  • Refresh scripts recompute every derived figure the same way the page does and fail on contract drift, so a page cannot quietly disagree with its data.
  • This site is exported from a private research workspace by a tested pipeline that strips internal paths and checks every link before publishing.
  • Built by directing AI coding agents: specs, review and verification by the author; code by the agents.
